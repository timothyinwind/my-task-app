專題一：高階三角函數與解三角形進階 基礎與壓軸工具
一、兩角和與差及二倍角公式（Sum/Difference & Double Angle Formulas）
1.1 核心公式與齊次化變換 DSE 必修無和差角

兩角和與差公式：

$$\sin(\alpha \pm \beta) = \sin\alpha \cos\beta \pm \cos\alpha \sin\beta$$ $$\cos(\alpha \pm \beta) = \cos\alpha \cos\beta \mp \sin\alpha \sin\beta$$ $$\tan(\alpha \pm \beta) = \frac{\tan\alpha \pm \tan\beta}{1 \mp \tan\alpha \tan\beta}$$

二倍角公式：

$$\sin 2\alpha = 2\sin\alpha \cos\alpha$$ $$\cos 2\alpha = \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$$ $$\tan 2\alpha = \frac{2\tan\alpha}{1 - \tan^2\alpha}$$
【典例解析】齊次化切化弦求值

題目：已知 $\tan\alpha = 2$，求 $\sin 2\alpha + \cos^2\alpha$ 的值。

解析：利用二倍角公式展開，並利用 $\sin^2\alpha + \cos^2\alpha = 1$ 進行齊次化構造：

$$\sin 2\alpha + \cos^2\alpha = \frac{2\sin\alpha \cos\alpha + \cos^2\alpha}{\sin^2\alpha + \cos^2\alpha}$$

分子分母同除以 $\cos^2\alpha$ 得：

$$\frac{2\tan\alpha + 1}{\tan^2\alpha + 1} = \frac{2(2) + 1}{2^2 + 1} = \frac{5}{5} = 1$$
二、輔助角公式（Auxiliary Angle Formula / Harmonic Combination）
2.1 形如 $a \sin x + b \cos x$ 的合一變換 高考高頻核心
$$\text{公式：} \quad a\sin x + b\cos x = \sqrt{a^2 + b^2} \sin(x + \varphi)$$

其中輔助角 $\varphi$ 滿足 $\tan\varphi = \frac{b}{a}$（$\varphi$ 所在的象限由點 $(a, b)$ 確定）。

用途： 將同頻率的不同名三角函數化為單一正弦型函數 $A\sin(\omega x + \varphi)$，從而求解週期、最值與單調性。

【典例解析】求解三角函數值域與最值

題目：求函數 $f(x) = \sqrt{3}\sin x - \cos x$ 在 $x \in [0, \pi]$ 上的最大值與最小值。

解析：提取 $\sqrt{a^2+b^2} = \sqrt{(\sqrt{3})^2 + (-1)^2} = 2$：

$$f(x) = 2 \left( \frac{\sqrt{3}}{2}\sin x - \frac{1}{2}\cos x \right) = 2\sin\left(x - \frac{\pi}{6}\right)$$

因為 $x \in [0, \pi]$，故 $x - \frac{\pi}{6} \in \left[-\frac{\pi}{6}, \frac{5\pi}{6}\right]$。

當 $x - \frac{\pi}{6} = \frac{\pi}{2}$（即 $x = \frac{2\pi}{3}$）時，取得最大值 $f(x)_{\max} = 2(1) = 2$；

當 $x - \frac{\pi}{6} = -\frac{\pi}{6}$（即 $x = 0$）時，取得最小值 $f(x)_{\min} = 2\sin\left(-\frac{\pi}{6}\right) = -1$。

三、解三角形進階衍生公式（Advanced Triangle Geometry）
3.1 面積、內切圓、外接圓與射影定理 高考壓軸必備

外接圓/內切圓面積通式：

$$S = \frac{1}{2}ab\sin C = \frac{abc}{4R} = p \cdot r$$

（其中 $R$ 為外接圓半徑，$r$ 為內切圓半徑，$p = \frac{a+b+c}{2}$ 為半周長）。

射影定理（第一餘弦定理）：

$$a = b\cos C + c\cos B, \quad b = a\cos C + c\cos A, \quad c = a\cos B + b\cos A$$
【典例解析】利用外接圓半徑與邊角關係解三角形

題目：在 $\Delta ABC$ 中，已知 $a = 2\sqrt{3}$，$b = 2$，且外接圓半徑 $R = 2$，求角 $C$。

解析：由正弦定理 $\frac{a}{\sin A} = 2R \implies \sin A = \frac{2\sqrt{3}}{4} = \frac{\sqrt{3}}{2}$。

同理 $\frac{b}{\sin B} = 2R \implies \sin B = \frac{2}{4} = \frac{1}{2}$。

若 $A = 60^\circ, B = 30^\circ$，則 $C = 180^\circ - 60^\circ - 30^\circ = 90^\circ$；

若 $A = 120^\circ, B = 30^\circ$，則 $C = 180^\circ - 120^\circ - 30^\circ = 30^\circ$。

專題二：微積分與導數應用 高考解答題壓軸專題
一、導函數基本運算法則與切線方程（Derivatives & Tangents）
1.1 核心求導法則與切線公式

乘除法求導法則：

$$[u(x)v(x)]' = u'(x)v(x) + u(x)v'(x)$$ $$\left[\frac{u(x)}{v(x)}\right]' = \frac{u'(x)v(x) - u(x)v'(x)}{[v(x)]^2}$$

基本初等函數導數： $(e^x)' = e^x$, $(\ln x)' = \frac{1}{x}$, $(\sin x)' = \cos x$, $(\cos x)' = -\sin x$

切線方程： 曲線 $y = f(x)$ 在點 $(x_0, f(x_0))$ 處切線方程為 $y - f(x_0) = f'(x_0)(x - x_0)$。

【典例解析】求商型函數的切線方程

題目：求曲線 $f(x) = \frac{\ln x}{x}$ 在點 $(1, 0)$ 處的切線方程。

解析：使用商的求導法則：

$$f'(x) = \frac{\left(\frac{1}{x}\right) \cdot x - \ln x \cdot 1}{x^2} = \frac{1 - \ln x}{x^2}$$

計算切線斜率 $k = f'(1) = \frac{1 - \ln 1}{1^2} = 1$。

代入點斜式：$y - 0 = 1(x - 1) \implies x - y - 1 = 0$。

二、導數判定函數單調性與極值（Monotonicity & Extrema）
2.1 單調區間與極值點判據

單調性： 在區間 $(a,b)$ 上，若 $f'(x) > 0$，則 $f(x)$ 單調遞增；若 $f'(x) < 0$，則 $f(x)$ 單調遞減。

一階導數極值判定： 若 $f'(x_0) = 0$：

① 當 $x < x_0$ 時 $f'(x) > 0$ 且 $x > x_0$ 時 $f'(x) < 0 \implies x_0$ 為極大值點；

② 當 $x < x_0$ 時 $f'(x) < 0$ 且 $x > x_0$ 時 $f'(x) > 0 \implies x_0$ 為極小值點。

【典例解析】求含指數函數的單調性與極值

題目：求函數 $f(x) = x e^{-x}$ 的單調遞增區間與極大值。

解析：求導得：

$$f'(x) = 1 \cdot e^{-x} + x \cdot (-e^{-x}) = (1 - x)e^{-x}$$

令 $f'(x) > 0$，因為 $e^{-x} > 0$，故 $1 - x > 0 \implies x < 1$。即單調遞增區間為 $(-\infty, 1)$。

當 $x > 1$ 時 $f'(x) < 0$，故 $x = 1$ 為極大值點，極大值為 $f(1) = 1 \cdot e^{-1} = \frac{1}{e}$。

三、高考壓軸：切線放縮不等式鏈（Tangent Scale Reduction Inequalities）
3.1 切線放縮神式與構造函數法 衝刺 140+ 必備

指對數切線放縮基本不等式鏈：

$$e^x \ge x + 1 \quad (\text{當且僅當 } x = 0 \text{ 取等號，常用於將指項放縮為一次項})$$ $$\ln x \le x - 1 \quad (\text{當且僅當 } x = 1 \text{ 取等號，常用於將對數項放縮為一次項})$$

衍生放縮公式： $e^x \ge e \cdot x$ ； $\ln x \le \frac{x}{e}$ ； $\sin x \le x \; (x \ge 0)$。

【典例解析】利用切線放縮證明不等式

題目：證明：當 $x > 0$ 時，$e^x > x + 1$ 恆成立。

證明：構造函數 $g(x) = e^x - x - 1$。

求導：$g'(x) = e^x - 1$。當 $x > 0$ 時，$e^x > 1 \implies g'(x) > 0$，故 $g(x)$ 在 $(0, +\infty)$ 上單調遞增。

因此 $g(x) > g(0) = e^0 - 0 - 1 = 0$，即 $e^x > x + 1$ 恆成立。

專題三：圓錐曲線與平面解析幾何進階 解析幾何大題核心
一、橢圓與雙曲線幾何性質與焦點三角形（Conic Properties & Focal Triangles）
1.1 焦點三角形面積公式與漸近線 DSE 必修無圓錐曲線

橢圓： $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \; (a > b > 0)$，$c = \sqrt{a^2 - b^2}$，離心率 $e = \frac{c}{a} \in (0,1)$。

$$\text{橢圓焦點三角形面積：} \quad S_{\Delta F_1 P F_2} = b^2 \tan\left(\frac{\theta}{2}\right) \quad (\text{其中 } \theta = \angle F_1 P F_2)$$

雙曲線： $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$，$c = \sqrt{a^2 + b^2}$，漸近線方程為 $y = \pm \frac{b}{a} x$。

【典例解析】秒殺橢圓焦點三角形面積

題目：已知橢圓 $\frac{x^2}{16} + \frac{y^2}{9} = 1$ 的左右焦點分別為 $F_1, F_2$，點 $P$ 在橢圓上，若 $\angle F_1 P F_2 = 60^\circ$，求 $\Delta F_1 P F_2$ 的面積。

解析：由方程得 $a^2 = 16, b^2 = 9$，張角 $\theta = 60^\circ$。

直接套用焦點三角形面積公式：

$$S = b^2 \tan\left(\frac{\theta}{2}\right) = 9 \cdot \tan(30^\circ) = 9 \cdot \frac{\sqrt{3}}{3} = 3\sqrt{3}$$
二、拋物線性質與焦點弦長公式（Parabola & Focal Chords）
2.1 拋物線標準方程與極座標弦長

拋物線： $y^2 = 2px \; (p > 0)$，焦點 $F\left(\frac{p}{2}, 0\right)$，準線 $x = -\frac{p}{2}$。焦半徑 $|PF| = x_0 + \frac{p}{2}$。

$$\text{過焦點弦長公式：} \quad L = \frac{2p}{\sin^2\alpha} \quad (\alpha \text{ 為焦點弦的傾斜角})$$ $$\text{通用弦長公式：} \quad L = \sqrt{1 + k^2} |x_1 - x_2|$$
【典例解析】利用傾斜角求焦點弦長

題目：求過拋物線 $y^2 = 4x$ 的焦點且傾斜角為 $60^\circ$ 的直線被拋物線截得的弦長。

解析：方程 $y^2 = 4x \implies 2p = 4 \implies p = 2$，傾斜角 $\alpha = 60^\circ$。

代入焦點弦長公式：

$$L = \frac{2p}{\sin^2 60^\circ} = \frac{4}{\left(\frac{\sqrt{3}}{2}\right)^2} = \frac{4}{\frac{3}{4}} = \frac{16}{3}$$
三、解析幾何壓軸運算化簡：中點弦點導法（Midpoint Chord Method）
3.1 點差法與中點斜率關係

設 $A(x_1, y_1), B(x_2, y_2)$ 為橢圓 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 上兩點，弦 $AB$ 中點為 $M(x_0, y_0)$，弦斜率為 $k_{AB}$，中點連線斜率為 $k_{OM} = \frac{y_0}{x_0}$，則滿足：

$$k_{AB} \cdot k_{OM} = -\frac{b^2}{a^2}$$
【典例解析】已知中點求割線方程

題目：求橢圓 $\frac{x^2}{4} + \frac{y^2}{3} = 1$ 被點 $M\left(1, \frac{1}{2}\right)$ 平分的弦所在直線方程。

解析：由橢圓方程知 $a^2 = 4, b^2 = 3$。中點 $M\left(1, \frac{1}{2}\right)$，故 $k_{OM} = \frac{\frac{1}{2}}{1} = \frac{1}{2}$。

套用點差法公式：

$$k_{AB} \cdot \left(\frac{1}{2}\right) = -\frac{3}{4} \implies k_{AB} = -\frac{3}{2}$$

由點斜式求直線方程：$y - \frac{1}{2} = -\frac{3}{2}(x - 1) \implies 3x + 2y - 4 = 0$。

專題四：空間向量與立體幾何定量計算 立體幾何解答題必考
一、空間向量坐標運算與平面法向量（Space Vectors & Normal Vector）
1.1 空間向量數量積與法向量求解

向量數量積： $\vec{a} \cdot \vec{b} = x_1 x_2 + y_1 y_2 + z_1 z_2 = |\vec{a}| |\vec{b}| \cos\theta$

平面法向量求解： 設 $\vec{u} = (x_1, y_1, z_1)$ 和 $\vec{v} = (x_2, y_2, z_2)$ 為平面內兩不共線向量，解方程組 $\vec{n} \cdot \vec{u} = 0$ 且 $\vec{n} \cdot \vec{v} = 0$ 求出法向量 $\vec{n} = (x, y, z)$。

【典例解析】求解平面的法向量

題目：已知平面內兩向量 $\vec{a} = (1, 2, 0)$，$\vec{b} = (0, 1, 1)$，求該平面的法向量 $\vec{n}$。

解析：設 $\vec{n} = (x, y, z)$，則：

$$\vec{n} \cdot \vec{a} = x + 2y = 0, \quad \vec{n} \cdot \vec{b} = y + z = 0$$

取 $y = -1$，則 $x = 2$，$z = 1$。故平面的法向量可取為 $\vec{n} = (2, -1, 1)$。

二、利用向量求夾角與點到平面距離（Angles & Distance via Vectors）
2.1 距離與三大夾角向量公式
$$\text{點到平面距離：} \quad d = \frac{|\vec{AB} \cdot \vec{n}|}{|\vec{n}|} \quad (A \text{ 為平面內任意一點，} B \text{ 為面外點，} \vec{n} \text{ 為法向量})$$ $$\text{線面角正弦值：} \quad \sin\theta = \frac{|\vec{d} \cdot \vec{n}|}{|\vec{d}| |\vec{n}|} \quad (\vec{d} \text{ 為直線方向向量})$$ $$\text{二面角餘弦值：} \quad |\cos\alpha| = \frac{|\vec{n}_1 \cdot \vec{n}_2|}{|\vec{n}_1| |\vec{n}_2|}$$
【典例解析】向量法求點到平面的距離

題目：已知點 $B(1, 1, 2)$，平面 $\alpha$ 過點 $A(0, 1, 0)$，其法向量為 $\vec{n} = (2, -1, 1)$，求點 $B$ 到平面 $\alpha$ 的距離。

解析：計算向量 $\vec{AB} = (1 - 0, 1 - 1, 2 - 0) = (1, 0, 2)$。

$$\vec{AB} \cdot \vec{n} = 1(2) + 0(-1) + 2(1) = 4$$

法向量模長 $|\vec{n}| = \sqrt{2^2 + (-1)^2 + 1^2} = \sqrt{6}$。

點到平面距離 $d = \frac{4}{\sqrt{6}} = \frac{2\sqrt{6}}{3}$。

三、多面體外接球幾何模型（Circumscribed Sphere Models）
3.1 牆角模型與直柱體模型

牆角模型（三條棱兩兩垂直）： 若三棱錐共頂點的三條棱長分別為 $a, b, c$ 且兩兩垂直，外接球半徑為：

$$R = \frac{1}{2} \sqrt{a^2 + b^2 + c^2}$$

漢堡模型（直棱柱/正多邊形柱）： 若柱體高為 $h$，底面外接圓半徑為 $r_{\text{底}}$，則外接球半徑滿足：

$$R^2 = r_{\text{底}}^2 + \left(\frac{h}{2}\right)^2$$
【典例解析】求解正三棱柱的外接球表面積

題目：底面邊長為 $2$、高為 $3$ 的正三棱柱，求其外接球的表面積。

解析：底面為邊長 $a=2$ 的正三角形，由正弦定理求底面外接圓半徑：

$$2 r_{\text{底}} = \frac{a}{\sin 60^\circ} = \frac{2}{\frac{\sqrt{3}}{2}} = \frac{4}{\sqrt{3}} \implies r_{\text{底}} = \frac{2}{\sqrt{3}}$$

代入漢堡模型公式：

$$R^2 = \left(\frac{2}{\sqrt{3}}\right)^2 + \left(\frac{3}{2}\right)^2 = \frac{4}{3} + \frac{9}{4} = \frac{43}{12}$$

外接球表面積 $S = 4\pi R^2 = 4\pi \left(\frac{43}{12}\right) = \frac{43}{3}\pi$。

專題五：數列高級求和與遞推數列解法 數列壓軸技巧
一、錯位相減法求和（Shift-Subtraction Method）
1.1 等差乘以等比型數列求和

適用對象： 通項為 $c_n = a_n \cdot b_n$，其中 $\{a_n\}$ 為等差數列，$\{b_n\}$ 為公比為 $q$ 的等比數列。

求和步驟： 寫出 $S_n$ 與 $q S_n$ 的展開式，兩式相減：

$$(1 - q)S_n = a_1 b_1 + \left( \sum_{k=2}^n d b_k \right) - a_n b_{n+1}$$
【典例解析】經典錯位相減求和

題目：求數列 $c_n = n \cdot 2^n$ 的前 $n$ 項和 $S_n$。

解析：列出和式：

$$S_n = 1 \cdot 2^1 + 2 \cdot 2^2 + 3 \cdot 2^3 + \dots + n \cdot 2^n \quad \text{--- (1)}$$

兩邊同乘以公比 $q = 2$ 得：

$$2S_n = 1 \cdot 2^2 + 2 \cdot 2^3 + \dots + (n-1) \cdot 2^n + n \cdot 2^{n+1} \quad \text{--- (2)}$$

(1) - (2) 得：

$$-S_n = 2^1 + 2^2 + 2^3 + \dots + 2^n - n \cdot 2^{n+1}$$

利用等比數列求和：

$$-S_n = \frac{2(2^n - 1)}{2 - 1} - n \cdot 2^{n+1} = 2^{n+1} - 2 - n \cdot 2^{n+1} = (1 - n)2^{n+1} - 2$$

故 $S_n = (n - 1)2^{n+1} + 2$。

二、裂項相消法求和（Partial Fractions Summation）
2.1 常見裂項拆分公式
$$\text{分式型：} \quad \frac{1}{n(n + k)} = \frac{1}{k} \left( \frac{1}{n} - \frac{1}{n + k} \right)$$ $$\text{奇數乘積型：} \quad \frac{1}{(2n - 1)(2n + 1)} = \frac{1}{2} \left( \frac{1}{2n - 1} - \frac{1}{2n + 1} \right)$$ $$\text{根號型：} \quad \frac{1}{\sqrt{n + 1} + \sqrt{n}} = \sqrt{n + 1} - \sqrt{n}$$
【典例解析】分式裂項相消求和

題目：已知 $a_n = \frac{1}{n(n + 1)}$，求前 $n$ 項和 $S_n$。

解析：將通項拆分為 $a_n = \frac{1}{n} - \frac{1}{n + 1}$。

展開累加：

$$S_n = \left(1 - \frac{1}{2}\right) + \left(\frac{1}{2} - \frac{1}{3}\right) + \dots + \left(\frac{1}{n} - \frac{1}{n + 1}\right)$$

中間項全部抵消，剩餘首尾項：

$$S_n = 1 - \frac{1}{n + 1} = \frac{n}{n + 1}$$
三、二階線性遞推數列：特徵根法（Characteristic Root Method）
3.1 二階常係數齊次遞推求解

遞推關係： $a_{n+2} = p a_{n+1} + q a_n$ （$p, q$ 為常數）。

特徵方程： $x^2 - px - q = 0$，設其兩根為 $x_1, x_2$。

通項公式： 若 $x_1 \neq x_2$，則 $a_n = c_1 x_1^{n-1} + c_2 x_2^{n-1}$，其中待定係數 $c_1, c_2$ 由首項 $a_1, a_2$ 代入確定。

【典例解析】求二階遞推數列通項

題目：已知 $a_1 = 1, a_2 = 3$，且 $a_{n+2} = 5a_{n+1} - 6a_n$，求通項 $a_n$。

解析：寫出特徵方程：$x^2 - 5x + 6 = 0 \implies (x - 2)(x - 3) = 0$，根為 $x_1 = 2, x_2 = 3$。

設通項 $a_n = c_1 \cdot 2^{n-1} + c_2 \cdot 3^{n-1}$。

代入 $n=1$ 與 $n=2$：

$$a_1 = c_1 + c_2 = 1, \quad a_2 = 2c_1 + 3c_2 = 3$$

聯立解得 $c_1 = 0, c_2 = 1$。故通項公式為 $a_n = 3^{n-1}$。

專題六：二項式定理、隨機變量分佈與高階不等式 概率與壓軸工具
一、二項式定理與通項公式（Binomial Theorem）
1.1 展開式與指定項係數求解 選修三 / M1

二項式定理：

$$(a + b)^n = C_n^0 a^n + C_n^1 a^{n-1}b + \dots + C_n^k a^{n-k}b^k + \dots + C_n^n b^n$$

通用第 $k+1$ 項通項： $T_{k+1} = C_n^k a^{n-k}b^k$ （注意：$T_{k+1}$ 表示展開式中的第 $k+1$ 項）。

【典例解析】求解二項式指定常數項

題目：求二項式 $\left(2x - \frac{1}{x}\right)^6$ 展開式中的常數項。

解析：寫出通項公式：

$$T_{k+1} = C_6^k (2x)^{6-k} \left(-\frac{1}{x}\right)^k = C_6^k 2^{6-k} (-1)^k x^{6-2k}$$

令 $x$ 的指數為零（常數項）：$6 - 2k = 0 \implies k = 3$。

代入第 4 項：$T_4 = C_6^3 2^{6-3} (-1)^3 = 20 \cdot 8 \cdot (-1) = -160$。

二、離散型隨機變量分佈（Binomial & Hypergeometric Distributions）
2.1 二項分佈與超幾何分佈期望值與方差

二項分佈 $X \sim B(n, p)$： 獨立重複試驗，期望值 $E(X) = np$，方差 $D(X) = np(1 - p)$。

超幾何分佈： 總數 $N$，指定類別數 $M$，抽取 $n$ 個，期望值 $E(X) = n \frac{M}{N}$。

【典例解析】二項分佈期望與方差快速求解

題目：某人射擊命中率為 $p = 0.8$，獨立射擊 $5$ 次，求命中次數 $X$ 的期望值 $E(X)$ 與方差 $D(X)$。

解析：顯然 $X$ 服從二項分佈 $X \sim B(5, 0.8)$。

期望值 $E(X) = np = 5 \times 0.8 = 4$。

方差 $D(X) = np(1 - p) = 5 \times 0.8 \times 0.2 = 0.8$。

三、高階不等式工具：柯西不等式與對數平均不等式
3.1 柯西不等式（Cauchy-Schwarz）與對數平均鏈 壓軸突破武器

柯西不等式： 對任意實數，

$$(a_1^2 + a_2^2)(b_1^2 + b_2^2) \ge (a_1 b_1 + a_2 b_2)^2$$

等號當且僅當 $\frac{a_1}{b_1} = \frac{a_2}{b_2}$ 時成立。

對數平均不等式鏈： 對任意 $a > b > 0$，

$$\sqrt{ab} < \frac{a - b}{\ln a - \ln b} < \frac{a + b}{2}$$

（導數大題「極值點偏移」破解利器）。

【典例解析】柯西不等式求條件最小值

題目：已知 $x, y > 0$ 且滿足 $x + 2y = 5$，求 $x^2 + y^2$ 的最小值。

解析：套用柯西不等式構造：

$$(x^2 + y^2)(1^2 + 2^2) \ge (x \cdot 1 + y \cdot 2)^2$$

代入已知條件：

$$(x^2 + y^2)(1 + 4) \ge (5)^2 \implies 5(x^2 + y^2) \ge 25 \implies x^2 + y^2 \ge 5$$

當且僅當 $\frac{x}{1} = \frac{y}{2}$（即 $x=1, y=2$）時，最小值為 $5$。
